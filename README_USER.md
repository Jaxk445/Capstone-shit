# User README

## Overview

This portal is used for internship operations, attendance tracking, task management, leave requests, discussions, and performance reviews. Your available actions depend on your role.

## Common Navigation

Most users will work through these areas:

- Dashboard
- Attendance
- Tasks
- Contributions
- Leave
- Performance Reviews
- Settings

## Supervisor

Supervisors can view and manage the team across all records.

### What Supervisors Can Do

- View the full dashboard overview for the internship team.
- Track all attendance records and export filtered attendance data.
- Approve, reject, or revise tasks submitted by interns.
- Create new tasks and assign them to one or more interns.
- Extend task deadlines when work needs more time.
- Review and approve leave requests.
- Adjust leave balances when needed.
- Create, review, and delete performance evaluations.
- Read and reply in the contributions or discussion board.
- Use the chatbot for portal help and task context.

### Supervisor Workflow

1. Sign in with a supervisor account.
2. Open Dashboard to review workload, approvals, and key metrics.
3. Use Attendance to monitor intern attendance and export records.
4. Use Tasks to assign work, review submissions, and update deadlines.
5. Use Leave to approve requests and manage balances.
6. Use Performance Reviews to create evaluation records.
7. Use Contributions to answer questions and leave feedback.

### Supervisor Tips

- Use the search and filter tools to focus on a specific intern.
- Check notifications before approving tasks or leave.
- When reviewing attendance, remember supervisors have broader access than interns.

## Interns

Interns can only access their own records and assigned work.

### What Interns Can Do

- View personal dashboard metrics and status.
- Clock in and clock out attendance using the attendance flow.
- Enroll or verify a face image when required for attendance.
- Submit task files for assigned work.
- Ask for deadline extensions only through the workflow provided in Tasks.
- Submit leave requests.
- Read their own performance review history.
- Post questions or updates in the contributions board.
- Use the chatbot for help with tasks and portal usage.
- Update profile settings, including avatar and password.

### Intern Workflow

1. Sign in with an intern account.
2. Check Dashboard for pending tasks, approvals, and leave status.
3. Open Attendance to clock in or clock out.
4. Open Tasks to review assigned work and upload submissions.
5. Open Leave to file a new leave request.
6. Open Contributions to ask questions or respond to discussions.
7. Open Performance Reviews to view evaluation history.
8. Open Settings to update profile details.

### Intern Tips

- Attendance requires GPS validation, and some flows also require face verification.
- You can only submit or edit tasks assigned to you.
- Leave requests and performance records are scoped to your own account.

## Getting Started

If you are unsure what to do first, start with Dashboard, then move to the section that matches your current work: Attendance for check-in, Tasks for deliverables, or Leave for time off.
